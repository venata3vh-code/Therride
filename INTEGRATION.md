# THERRIDE — Facebook каталог, Supabase, GitHub и Netlify

Актуализация: 2 ноември 2026, Europe/Sofia.

## Реални данни и текущо състояние

Повторно проверени са 114 публични Facebook публикации и 133 ценови наблюдения. Каталогът съдържа 106 нормализирани артикула / 137 варианта. От тях 103 артикула / 134 варианта са изрично за Light Bee X/S или Ultra Bee и са внесени в Supabase. Общият видим магазин съдържа 147 позиции.

Гуменият предпазител за задния амортисьор е открит при повторната проверка като отделен пропуснат артикул: 30 € → 25 €. Старите източници и стабилните ID са запазени.

Наличностите започват от 10 за вариант, но са непотвърдени. Новите продукти се виждат със запитване. Двете противоречиви цени са null и не се представят като 0 €. Оригиналните цени са само във вътрешните данни и административния CSV.

## Supabase

Проект: abbwqzvlprpjkfmssktf.

Миграцията supabase/migrations/20261102114616_facebook_catalogue_inquiries.sql вече е приложена. Публичните products съдържат 103 внесени Facebook артикула и 44 останали предишни позиции. Пет съпоставени продукта запазват старите си ID и адреси; новите адреси са алиаси. Първоначалните записи са архивирани в private.catalogue_import_backups. Пълните 106 изходни продукта с оригинални цени са в private.catalogue_product_sources и нямат клиентски права.

Режимът inquiry позволява видимост с непотвърдена наличност и при нужда празна цена. Сървърните проверки не позволяват покупка на такива артикули. Количките със стари ID и съществуващият checkout са запазени. Администраторът може да променя количества, текстове, снимки и видимост. След действителния импорт базата има предимство; статичният резервен файл не връща скрити артикули и не отменя редакциите.

## GitHub и build

Хранилище: https://github.com/venata3vh-code/Therride

Изискване: Node 24, npm ci, след това:

```sh
npm test
npm run catalog:validate
npm run build
node scripts/verify-import-render.mjs
```

Build-ът генерира dist/ с 164 HTML страници плюс 404. Използва проверения catalog/published-snapshot.json и публичния каталог, без да изисква service_role ключ при компилация. Публичната Supabase връзка е конфигурирана. Сървърни секретни ключове никога не се записват във VITE променливи или хранилището.

При бъдещо изрично публикуване от административен JSON/CSV:

```sh
node therride-product-import.js --check
node therride-product-import.js --supabase --publish-inquiries
```

Тази команда изисква сървърни SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY и приложената миграция. По подразбиране --supabase без --publish-inquiries подготвя чернови. Повторно публикуване пази вече внесените редакции и количества. Изходната цена се пази във вътрешния JSON/CSV; частният регистър в настоящата база е внесен чрез избрания Supabase plugin.

## Netlify

netlify.toml е настроен за npm run build и директория dist/. Поддържа продуктови и моделни адреси, 404, старите пренасочвания, кеширане и защитните заглавки. public/_redirects и public/_headers осигуряват същите необходими маршрути и при директно качване на готовите статични файлове.

Готовият THERRIDE-Netlify-2026-11-02.zip съдържа съдържанието на dist/ в корена и може да се качи директно. Пълният проектен архив съдържа изходния код, продуктовата база, CSV, снимковия регистър и готовия build.

**Публикуване в Netlify не е завършено.** Браузърът беше на екран за вход, беше избран Google, а следващата защитена заявка за вход беше отказана. Не е създаван нов Netlify акаунт и не е подменян хостингът.
